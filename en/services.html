Building on what you already have

Already have software? Let’s move it forward.

I can work on existing applications to add features, fix problems and adapt workflows to new needs. Before making changes, I examine the code and how the application is used.

Working together

Analyse. Build step by step. Improve.

  1. Understand the problem

    We start with the people, activities and tools involved. I gather needs and constraints to structure the work and define what to build.

  2. Build and review

    I work step by step, reviewing features and how they’re used. The code should become a tool that makes sense to the people using it.

  3. Evolve the solution

    Using the software brings new needs to light. I can help with maintenance, debugging and the next set of features.
